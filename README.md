# Retail Sales Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project explores retail sales data using Python to identify sales trends, product category performance, and customer purchasing patterns. The goal is to extract meaningful business insights through data analysis and visualization.

## 🎯 Objectives
- Analyze overall retail sales and transaction data.
- Identify product categories with the highest revenue.
- Examine monthly sales trends.
- Analyze sales by gender and customer age groups.
- Compare product quantities sold and average transaction values.
- Perform data quality checks.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## 📂 Dataset
The dataset contains 1,000 retail transactions and 9 original columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 🔍 Analysis Performed
1. Loaded and inspected the dataset.
2. Checked missing values and duplicate records.
3. Converted dates into a datetime format.
4. Calculated total revenue, unique transactions, and unique customers.
5. Analyzed sales by product category.
6. Examined monthly sales trends.
7. Compared sales by gender and age group.
8. Analyzed quantities sold and average transaction values.
9. Created charts to visualize sales patterns.

## 📊 Key Findings
The analysis is designed to identify:
- The product category generating the highest revenue.
- The month with the highest sales.
- Customer segments contributing the most sales.
- Differences between category revenue and quantity sold.
